NOVA Downloader — إصدار منظم مع شريط جانبي
==========================================
تمت إعادة تنظيم الواجهة بناءً على ملاحظتك:
- إعادة الشريط الجانبي للتنقل بين الرئيسية والتنزيلات والإعدادات.
- على الكمبيوتر يظهر الشريط ثابتاً، وعلى الهاتف يفتح من زر القائمة.
- إزالة الزخارف والأقسام الترويجية غير الضرورية.
- إبقاء الوظائف الأساسية فقط: تحليل الرابط، اختيار الصيغة والجودة، بدء التنزيل، متابعة التقدم وحفظ الملف.
- اعتماد ألوان الأخضر الغابي والزيتي والبيج المستوحاة من الصورة.

التشغيل:
Android عبر Termux: شغّل bash start_termux.sh ثم افتح http://127.0.0.1:8765 في Chrome.
Windows: شغّل start_windows.bat بعد تثبيت Python وFFmpeg.
Linux/macOS: شغّل ./start_linux_mac.sh بعد تثبيت Python وFFmpeg.

تنبيه: دعم المواقع يعتمد على yt-dlp ولا يمكن ضمان كل روابط المشاهدة. لا يتجاوز المشروع DRM أو قيود الوصول. نزّل فقط ما تملك حق تنزيله أو يسمح الموقع بتنزيله.
