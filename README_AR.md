# NOVA Downloader

مشروع Android أولي بلغة Kotlin وواجهة Jetpack Compose.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `NOVA_Downloader` في Android Studio.
3. انتظر مزامنة Gradle وتنزيل الاعتماديات.
4. شغّل التطبيق على محاكي أو هاتف Android.

## الموجود حالياً
- واجهة عربية داكنة بألوان بنفسجية وسماوية.
- إدخال رابط الفيديو.
- اختيار MP4 / MP3 / WEBM.
- اختيار جودة مبدئية.
- قائمة تجريبية للعناصر المضافة مع إمكانية حذفها.

## مهم
هذه نسخة واجهة أولية وليست أداة تنزيل مكتملة. زر الإضافة ينشئ عنصراً تجريبياً فقط.
لم تتم إضافة مراقبة الحافظة أو خدمة تنزيل فعلية أو تحويل الصيغ. يلزم تطوير هذه الأجزاء لاحقاً، مع احترام شروط المنصات وحقوق تنزيل المحتوى.
