# Vaulty – خزنتي

خزنة كلمات مرور شخصية تعمل بالكامل على جهازك: **بلا خادم، بلا اتصال بالإنترنت، بلا مكتبات خارجية.**
A personal password vault that runs entirely on your device: no server, no network, no third-party libraries.

## طريقة التشغيل / How to run

**الأسهل (يتطلب Python 3 فقط):**
```
cd vaulty
python3 serve.py
```
ثم افتح `http://localhost:8080` في المتصفح. (على ويندوز: `python serve.py`)

**بدائل:** `npx serve .` أو أي خادم ملفات ثابتة آخر. افتح التطبيق عبر `localhost` أو `https://` فقط،
لأن واجهة التشفير في المتصفح (Web Crypto) لا تعمل على عنوان `http://` عادي غير محلي.
يمكن أيضاً فتح `index.html` مباشرة في Chrome/Edge/Firefox، لكن التثبيت كتطبيق (PWA) والعمل دون اتصال
بعد الإغلاق يحتاجان `localhost` أو HTTPS.

**التثبيت كتطبيق:** من متصفح الهاتف أو الحاسوب اختر «تثبيت» / «إضافة إلى الشاشة الرئيسية».
بعد أول تحميل يعمل التطبيق دون إنترنت.

**للنشر على الهاتف:** ارفع مجلد المشروع إلى أي استضافة ثابتة تدعم HTTPS (GitHub Pages، Netlify…)؛ المجلد كله ملفات ثابتة.
بياناتك لا تُرفع: تبقى في المتصفح على جهازك فقط.

## الأمان / Security

| الجانب | التنفيذ |
|---|---|
| تشفير البيانات | AES-256-GCM عبر Web Crypto. كل حساب يُشفَّر منفرداً بـ IV عشوائي جديد |
| اشتقاق المفتاح | PBKDF2-HMAC-SHA256 بـ 600,000 تكرار وملح عشوائي 16 بايت (المفتاح غير قابل للاستخراج من المتصفح) |
| كلمة المرور الرئيسية | لا تُخزَّن أبداً. يُخزَّن فقط الملح + معاملات الاشتقاق + قيمة تحقق مشفّرة |
| سلامة البيانات | وسم GCM + ربط كل سجل بمعرّفه (AAD)، فأي تعديل أو تبديل للسجلات يُكتشف |
| التخزين | IndexedDB: نصوص مشفّرة فقط (اختبار آلي يتحقق أنه لا يوجد نص واضح) |
| القفل التلقائي | بعد عدم نشاط (1–60 دقيقة) وعند العودة إلى التبويب بعد خمول. يُفرَّغ المفتاح والبيانات من الذاكرة |
| تأخير المحاولات | بعد 3 محاولات خاطئة يزداد الانتظار تدريجياً (حتى 30 ثانية) |
| الحافظة | تُمسح بعد 10–60 ثانية (الافتراضي 20) وعند القفل |
| النسخ الاحتياطي | ملف `.vaulty` مشفّر بكلمة مرور تختارها. يُتحقق من سلامته وكلمة المرور قبل أي استعادة، والدمج لا يحذف شيئاً |
| الواجهة | لا `innerHTML` (البيانات تُعرض كنص فقط)، وسياسة CSP تمنع أي سكربت أو اتصال خارجي، وروابط الفتح http/https فقط |
| الشبكة | لا يوجد أي طلب شبكة. مصدر الـ service worker يخزّن ملفات التطبيق فقط لا بياناتك |

### ملاحظة صريحة حول Argon2id
طلبتَ Argon2id «أو بديل موثوق». **استخدمتُ PBKDF2-SHA256 (600,000 تكرار)** لأن Argon2id غير متوفر في Web Crypto،
وتنفيذه يحتاج مكتبة WebAssembly خارجية، وهذا يخالف شرط «مستقل بلا اعتماديات» وتعذّر تنزيلها أثناء البناء.
PBKDF2 معيار مدروس وموصى به (OWASP)، لكنه أضعف من Argon2id أمام العتاد المخصص (GPU/ASIC) لتخمين كلمات المرور.
لذلك: **اختر كلمة مرور رئيسية طويلة** (عبارة من 4 كلمات أو أكثر). معاملات الاشتقاق مخزّنة مع البيانات،
فيمكن لاحقاً إضافة Argon2id دون كسر الخزائن الحالية.

### حدود يجب أن تعرفها
- **لا يوجد استرجاع لكلمة المرور الرئيسية.** إن نسيتها فالبيانات غير قابلة للاسترداد (هذا هو المطلوب أمنياً).
- مسح بيانات المتصفح/الموقع **يمسح الخزنة**. صدّر نسخة احتياطية دورياً واحفظها في مكان آمن، وتذكّر كلمة مرورها.
- التطبيق لا يحميك من برمجيات خبيثة على جهازك ولا من تسجيل لوحة المفاتيح.
- مسح الحافظة يكتب نصاً فارغاً بعد المدة، فإن نسخت شيئاً آخر خلالها فسيُستبدل أيضاً.
- يعمل القفل التلقائي أثناء بقاء التبويب مفتوحاً؛ أغلق الخزنة يدوياً عند الابتعاد.

## بنية المشروع
```
index.html            الصفحة الوحيدة (وسياسة CSP)
css/styles.css        التصميم (ليلي/نهاري، RTL/LTR، Mobile First)
js/crypto.js          اشتقاق المفتاح، AES-GCM، صيغة النسخة الاحتياطية
js/vault.js           منطق الخزنة: إنشاء/فتح/حفظ/تغيير الرئيسية/استيراد
js/storage.js         IndexedDB (والذاكرة للاختبارات)
js/generator.js       المولّد، قياس القوة، كشف الضعيف/المكرر
js/i18n.js            الترجمة عربي/إنجليزي
js/app.js             الواجهة
sw.js, manifest…      العمل دون اتصال والتثبيت
tests/run.js          اختبارات الوحدة (Node 18+، بلا اعتماديات)
tests/e2e.py          اختبار شامل في Chromium (للتطوير فقط، يحتاج Playwright)
serve.py              خادم محلي صغير
```

## الاختبارات
```
node tests/run.js                 # 18 اختباراً للتشفير والخزنة والنسخ الاحتياطي والمولّد
pip install playwright && playwright install chromium
python3 tests/e2e.py              # 40 فحصاً على الواجهة الحقيقية
```
كلمات المرور في ملفات الاختبار قيم وهمية للاختبار فقط. لا توجد أي أسرار حقيقية في المشروع.
