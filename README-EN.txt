BO MANSOOR WORKSHOP MANAGEMENT – ENGLISH LANGUAGE SUPPORT

This release adds a persistent Arabic / English interface language selector.

HOW TO CHANGE THE LANGUAGE
1. Open Settings & Backup from the main navigation.
2. Find the Interface Language section.
3. Select English or العربية.
4. The application immediately changes language and layout direction. Your choice is saved locally on this device and remains selected after reload.

WHAT IS LOCALIZED
- Main navigation and application shell
- Dashboard, customers, projects, quotations, production, inventory, purchasing, installation, invoices, expenses, reports, and settings screens
- Common forms, field labels, status badges, prompts, and action buttons
- Quotation PDF labels and headings follow the selected language; the supplied workshop header/footer artwork remains unchanged.

DATA SAFETY
The language preference is stored in the existing settings object in the local database. Existing customer, project, quotation, and financial records are not translated or modified. Arabic remains the default language for existing installations unless English is selected.

The application remains offline-first and uses the browser's local storage as before.
