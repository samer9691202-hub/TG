NOVA DOWNLOADER — WEB PROJECT

تشغيل البرنامج:
1. فك ضغط الملف.
2. افتح index.html باستخدام Chrome أو Edge.
3. يعمل تنظيم الروابط محلياً دون خادم، وتُحفظ القائمة في تخزين المتصفح.

المحتويات:
- index.html: بنية التطبيق.
- style.css: التصميم المتجاوب.
- app.js: التفاعلات وحفظ القائمة.
- README-AR.txt: هذا الدليل.

الوظائف الموجودة:
- واجهة عربية داكنة حديثة.
- إدخال رابط ولصقه من الحافظة عند منح المتصفح الإذن.
- اختيار الصيغة والجودة كبيانات للقائمة.
- قائمة حديثة بالروابط وإمكانية حذفها.
- حفظ محلي عبر localStorage.

تنبيه:
هذه نسخة ويب أولية مماثلة من حيث صيغة التسليم لمشروع ZIP السابق (HTML/CSS/JavaScript).
لا تنفذ تنزيل ملفات الفيديو أو تحويلها فعلياً، ولا تراقب الحافظة في الخلفية.
إضافة محرك تنزيل حقيقي تتطلب تكاملاً تقنياً مناسباً ومراعاة شروط المنصة وحقوق المحتوى.
