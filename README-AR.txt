NOVA DOWNLOADER — نسخة المتصفح بدون خادم
==========================================

هذه النسخة تعمل كواجهة ثابتة يمكن نشرها على Vercel أو أي استضافة صفحات ثابتة.
لا تحتاج Python أو خادم تنزيل أو ملف API.

طريقة النشر:
1) فك ضغط الملف.
2) افتح مجلد NOVA-Downloader.
3) ارفع محتويات المجلد إلى مشروع Vercel الحالي (استبدل الملفات القديمة).
4) أعد النشر Deploy.

ما الذي يعمل؟
- فحص رابط مباشر لملف وسائط بامتداد MP4 / M4V / WEBM / MP3 / M4A / OGG / OGV / WAV.
- محاولة جلب الملف داخل المتصفح وإظهار تقدم التحميل.
- حفظ الملف على جهاز المستخدم.
- سجل محلي للعمليات في نفس المتصفح.

حدود مهمة:
- لا يمكن للمتصفح استخراج ملف الفيديو من صفحة مشاهدة مثل YouTube أو Qesen.
- لا يمكن تجاوز DRM أو تسجيل الدخول أو الاشتراكات أو قيود الوصول.
- قد يمنع الموقع المصدر جلب الملف من نطاق Vercel بسبب CORS. عندها لن يعمل التنزيل داخل الصفحة؛ هذه قيود يفرضها المصدر والمتصفح ولا يمكن إزالتها من الواجهة وحدها.
- لا يتم تنزيل الفيديو تلقائياً بمجرد لصق الرابط؛ افحص الرابط ثم اضغط حفظ الملف.
- استخدم الأداة فقط للمحتوى الذي تملك حق تنزيله أو الذي يسمح مصدره بالتنزيل.

ملاحظة:
هذه النسخة تستبدل محرك yt-dlp السابق بالكامل بوضع المتصفح المباشر.
