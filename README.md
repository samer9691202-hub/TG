# Vaulty V1.0 — خزنتي

مدير كلمات مرور محلي مستقل يعمل في المتصفح.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث يدعم Web Crypto. إذا منع المتصفح التشفير عند فتح الملف مباشرة، شغّله عبر localhost أو استضافة HTTPS.
3. أنشئ كلمة مرور رئيسية قوية لا تقل عن 12 حرفاً.
4. أضف حساباتك. تُشفّر البيانات باستخدام AES-256-GCM ومفتاح مشتق عبر PBKDF2-HMAC-SHA-256 (600,000 تكرار).

## الميزات في V1.0
- إنشاء خزنة وفتحها بكلمة مرور رئيسية.
- تشفير السجلات قبل تخزينها محلياً.
- إضافة وتعديل وحذف الحسابات.
- بحث وتصنيفات ومفضلة.
- نسخ اسم المستخدم وكلمة المرور.
- مولّد كلمات مرور.
- تصدير واستيراد نسخة احتياطية مشفّرة.

## تنبيهات أمنية مهمة
- كلمة المرور الرئيسية لا تُخزّن. إذا نسيتها فلن يمكن فك تشفير الخزنة.
- لا توجد مزامنة سحابية في هذا الإصدار؛ البيانات تبقى في تخزين المتصفح على الجهاز.
- لا تمسح بيانات المتصفح أو مساحة الموقع قبل إنشاء نسخة احتياطية مشفّرة.
- لا تستخدم جهازاً مشتركاً أو مخترقاً لحفظ كلمات مرور حساسة.
- هذا إصدار أولي عملي، لكنه لم يخضع لتدقيق أمني مستقل أو اختبار اختراق. لا تعتبره بديلاً معتمداً لمدير كلمات مرور مدقق أمنياً إلى أن يتم إجراء مراجعة متخصصة.
- استخدم HTTPS أو localhost لضمان تفعيل Web Crypto والحافظة في المتصفح.
