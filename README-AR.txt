NOVA Downloader — تصميم مستوحى من الطبيعة
=========================================
تم تحديث الهوية البصرية استلهاماً من الصورة المرجعية: أخضر الغابات، درجات الزيتون، البيج الدافئ، ولمسات الخشب. أضيفت واجهة افتتاحية واسعة، بطاقات مزايا، أقسام ترويجية، وبطاقات للتنزيلات، مع الحفاظ على وظائف محرك التنزيل.

التشغيل على Android:
1) ثبّت Termux من مصدر موثوق.
2) فك ضغط المشروع داخل مجلد يسهل الوصول إليه.
3) افتح Termux وانتقل إلى مجلد NOVA-Downloader.
4) نفّذ: bash start_termux.sh
5) افتح Chrome على الهاتف: http://127.0.0.1:8765
6) أدخل رابطاً، حلّل الرابط، اختر الصيغة والجودة، ثم ابدأ التنزيل.
7) بعد الاكتمال يحاول المتصفح حفظ الملف على الجهاز؛ ويمكن استخدام زر «حفظ الملف على الجهاز».

Windows:
ثبّت Python 3.10+ وFFmpeg، ثم شغّل start_windows.bat وافتح http://127.0.0.1:8765

Linux/macOS:
ثبّت Python 3.10+ وFFmpeg، ثم شغّل ./start_linux_mac.sh وافتح http://127.0.0.1:8765

المتطلبات:
- Python 3.10 أو أحدث.
- FFmpeg لدمج الصوت والصورة والتحويل إلى MP3.
- اتصال إنترنت لتثبيت المكتبات وتشغيل المواقع المدعومة.

تنبيه:
المشروع يستخدم yt-dlp ويدعم المواقع التي يستطيع المحرك تحليلها فقط؛ لا يوجد ضمان لكل موقع أو رابط، بما في ذلك Qesen. لا يتجاوز DRM أو تسجيل الدخول أو الاشتراكات أو قيود الوصول. استخدمه فقط للمحتوى المسموح بتنزيله قانونياً وبموجب شروط الموقع.
